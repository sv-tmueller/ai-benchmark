# AI Benchmark — Prompt Corpus & Artifacts

A curated collection of benchmark prompts and the resulting model outputs.

Two things live here:

- **`prompts/`** — 29 TOML prompt definitions spanning coding, reasoning,
  math, summarization, creative-writing, instruction-following,
  game-generation, app-generation, domain-probes, vision, and
  ServiceNow-style consulting tasks.
- **`results/`** — collected outputs: playable HTML game/app artifacts
  generated by various models, plus a sample benchmark JSON/Markdown
  report pair.

---

## Prompts

One TOML file per prompt. Core fields: `id`, `title`, `category`,
`difficulty`, `temperature`, `max_tokens`, and a `[system]`/`[user]` text
pair. Game/app prompts specify single-HTML or Vite+framework deliverables;
probes test constraint adherence, nonexistent-API handling, timing-safe
code, push-back behavior, and spec compliance.

| Area | Files |
|---|---|
| Games | `game-*.toml` (minecraft, cities-skylines, melon-jelly, horror house, mario kart, lava lamp, sunset ocean, meridian launch, last flight, stillwater app) |
| Domain probes | `probe-*.toml` (constrained scheduling, callback pyramid, constrained scheduling, find-the-bug, follow-spec, nonexistent-api, push-back, timing-safe-token) |
| Reasoning / Math | `reasoning-seating-puzzle.toml`, `math-addition.toml`, `math-second-derivative.toml` |
| Writing / Summaries | `creative-water-bottle.toml`, `summarize-article.toml`, `instruction-decline-meeting.toml` |
| Data / SQL | `sql-country-analytics.toml` |
| Vision | `vision-shape-count.toml` (uses `prompts/assets/shapes.png`) |
| Parameterized | `param-translate.toml` + `param-translate.fixtures.toml` |
| Enterprise / ITSM | `servicenow-service-catalog.toml` |

## Results

`results/artifacts/` holds the shipped HTML artifacts (Melon Jelly
variants across six models, Angry Birds on GLM 5.2);
`results/benchmark_*.json|.md` is a sample full-run report.

## CI

Lightweight validation only: every TOML must parse and every prompt TOML
must declare `id` and a non-empty `user` payload
([workflow](.github/workflows/ci.yml)).
