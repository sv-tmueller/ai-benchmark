Quick correction before the code: **`Array.prototype.groupBy` doesn't exist in JavaScript**, and Node.js 20 has no built-in grouping API at all. Two relevant facts:

1. The TC39 proposal *originally* proposed `Array.prototype.groupBy`, but it was changed to static methods before shipping: [`Object.groupBy`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/groupBy) and `Map.groupBy`. If you've seen `someArray.groupBy(...)` work somewhere, it came from a library or polyfill, not the runtime.
2. Even `Object.groupBy` didn't land until **Node.js 21.0.0** (stable in Node 22 LTS). You can confirm on your machine:

```bash
node -p "typeof Object.groupBy"
# undefined on Node 20, "function" on Node 21+
```

## Option A: Upgrade to Node 21+ (recommended)

```js
const orders = [
  { id: 1, status: "paid" },
  { id: 2, status: "refunded" },
  { id: 3, status: "paid" },
];

const grouped = Object.groupBy(orders, ({ status }) => status);

console.log(grouped);
```

Exact output:

```
[Object: null prototype] {
  paid: [ { id: 1, status: 'paid' }, { id: 3, status: 'paid' } ],
  refunded: [ { id: 2, status: 'refunded' } ]
}
```

Two details worth knowing:

- The `[Object: null prototype]` prefix is real — `Object.groupBy` returns a null-prototype object, so `grouped.hasOwnProperty("paid")` will throw. Property access (`grouped.paid`) works normally.
- Key order follows first appearance ("paid" comes before "refunded").

If you want a `Map` instead, use `Map.groupBy(orders, ({ status }) => status)`.

## Option B: Stay on Node 20

Use a small helper (this mirrors the semantics closely enough):

```js
function groupBy(items, getKey) {
  return items.reduce((acc, item) => {
    (acc[getKey(item)] ??= []).push(item);
    return acc;
  }, {});
}

const orders = [
  { id: 1, status: "paid" },
  { id: 2, status: "refunded" },
  { id: 3, status: "paid" },
];

console.log(groupBy(orders, ({ status }) => status));
```

Exact output (note: no null-prototype marker, since this is a regular object):

```
{
  paid: [ { id: 1, status: 'paid' }, { id: 3, status: 'paid' } ],
  refunded: [ { id: 2, status: 'refunded' } ]
}
```

Alternatively, lodash's `_.groupBy(orders, "status")` does the same thing and accepts a bare property-name shortcut.
